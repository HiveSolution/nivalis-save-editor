Get started

WINDOWS10 / 11
  1. Download the zip and extract it anywhere.
  2. Run NivalisSaveEditor.exe. If Windows warns you, click More info, then Run anyway.
  3. Pick a save, change what you like and click Save changes.
  4. Load that save in the game.

You can edit manual saves while the game is running. The autosave can only be changed once the game is closed. Needs WebView2, which most PCs already have.

LINUXx86_64

Download the AppImage, then run:

$ chmod +x NivalisSaveEditor-Linux-x86_64.AppImage
$ ./NivalisSaveEditor-Linux-x86_64.AppImage

For 64-bit Linux with the game installed through Steam (Proton).

Is it safe?

Your browser, Windows or your antivirus may warn you about this download. Here's why, and how you can check it yourself.

The editor isn't code-signed Signing certificates are expensive for a free tool, so Windows can't tell who made it, and security tools are often wary of new programs like this. New versions can also be held for manual review on Nexus Mods for the same kind of reason.
